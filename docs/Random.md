# 随机数 (Random)

生成指定闭区间 [min, max] 内的高质量伪随机整数。

## 运行参数

* **最小值 (`min`)**
  * 类型: `string`
  * 默认值: `"0"`
  * 描述: 随机数生成的下限数值。
* **最大值 (`max`)**
  * 类型: `string`
  * 默认值: `"100"`
  * 描述: 随机数生成的上限数值。

## 输出

* 类型: `number`
* 描述: 生成的区间内随机整数。

## 使用示例

```json
{
  "tag": "Random",
  "min": "1",
  "max": "100"
}
```

# 写入内存 (WriteMemory)

向目标软件进程或模块内存地址写入数据，支持自动解除页面写保护与多级偏移解析。

## 运行参数

* **目标进程 (`app`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 目标进程名称、PID 或标识。
* **驱动模式 (`backend`)**
  * 类型: `string`
  * 默认值: `"auto"`
  * 描述: 内存写入驱动模式。支持 `"auto"`（推荐自动模式）。
* **内存地址 (`address`)**
  * 类型: `string`
  * 默认值: `"0x0"`
  * 描述: 十六进制内存地址或基址（例如 `0x7FF710000000`）。
* **数据类型 (`data_type`)**
  * 类型: `string`
  * 默认值: `"i32"`
  * 描述: 写入数据格式。可选值：`i32`, `i64`, `u32`, `u64`, `f32`, `f64`, `string_utf8`, `string_utf16`, `bytes`, `hex`。
* **写入数值/内容 (`value`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 待写入的数据数值、文本或十六进制字节串。
* **指针偏移 (`offsets`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 多级指针偏移链（例如 `0x10,0x28`，留空为直接寻址）。
* **自动解除写保护 (`unprotect`)**
  * 类型: `string`
  * 默认值: `"true"`
  * 描述: 写入前是否自动临时修改内存页面保护属性。可选值：`"true"`, `"false"`。
* **通道连接配置 (`memflow_connector`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 外部直连或通道配置（高级可选参数，普通场景保留为空即可）。

## 输出

* 类型: `bool`
* 描述: 是否成功写入数据到目标内存地址。

## 使用示例

```json
{
  "tag": "WriteMemory",
  "app": "game.exe",
  "backend": "auto",
  "address": "0x7FF700100000",
  "data_type": "i32",
  "value": "999",
  "offsets": "0x48,0x10",
  "unprotect": "true",
  "memflow_connector": ""
}
```
